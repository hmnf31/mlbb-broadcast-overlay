Buat paket overlay untuk streaming

Satu profil untuk satu pertandingan. Tiap profil punya URL sendiri, jadi profil milik orang lain tidak akan menyentuh profil Anda.

1. Pilih paket overlay

Paket menentukan layout, style, dan ROI bawaan profil baru.

2. Detail profil

URL profil dibuat acak dan tidak bisa ditebak.

2b. Profil siap dipakai

ownerKey hanya disimpan di browser ini dan tidak pernah ikut ke server. Kalau kamu ganti perangkat, pakai panel "Profil saya" di bawah untuk menempelkan ulang.

3. Library aset

Aset bawaan paket. Gambar disalin ke assets/ lalu dibaca dari assets/registry.json.

4. Profil saya

Disimpan di browser ini. ownerKey hanya ada di perangkat ini, jadi OV browser yang berbeda tidak otomatis bisa mengedit.

Alat ownerKey

Kalau Anda kehilangan ownerKey, masukkan ownerKey lama untuk memverifikasi ulang. Hash ownerKey tidak pernah dikirim balik ke server dalam bentuk apa pun.

5. Ekspor / Impor

Export menghasilkan bundel JSON tanpa ownerKey. Import selalu membuat profil baru dengan slug dan ownerKey baru.

5. Galeri paket

Publish profil Anda ke galeri publik supaya orang lain bisa melihat dan menyalin Gayanya. ownerKey dan isi state tidak pernah ikut tersimpan, hanya nama paket dan nama tim. Tekan Publish di kartu profil untuk masuk atau keluar galeri.
